# Tech Store

Proyecto de tienda online de productos tecnológicos desarrollado con HTML y CSS. El objetivo es practicar la creación de layouts tipo e-commerce utilizando Grid y Flexbox, junto con diseño responsive.

---

## Demo del proyecto

Este proyecto simula una tienda de tecnología con categorías, productos y un diseño estructurado tipo dashboard e-commerce.

---

## Tecnologías utilizadas

- HTML5
- CSS3
- Grid Layout
- Flexbox
- Font Awesome (íconos)
- Diseño responsive

---

## Funcionalidades

- Barra de navegación simple con título e ícono
- Sidebar con categorías de productos y contadores
- Catálogo de productos en formato grid
- Tarjetas de productos con imagen, nombre, precio y botón de compra
- Footer básico
- Diseño tipo tienda tecnológica moderna
